### Security

**[Watchpost](https://github.com/talalkashar/watchpost)** is a SIEM in pure Python with no dependencies: log ingest, explainable detections mapped to MITRE ATT&CK, incident correlation and triage, with a tamper-evident audit log. Sigma rules import is checked against the SigmaHQ corpus, and every push runs lint, CodeQL and tests on Python 3.11 to 3.14.
